# Stage 0. Name

Before the scenario. Re-checked before every save. Until the name passes three checks, stage 1 does not begin.

## The rule

**A name names the subject.** Not a mood, not a material, not an epithet.

## Three checks

### 1. Substitution

Say it out loud: "I made ___". If the listener asks "made what?", the name is empty.

    "I made Voidframe"                          → made what?  FAIL
    "I made a map of three years of my work"    → clear.      PASS

### 2. Portability

Hold the name up against any other piece in the project. If it fits, it is not a name but a genre label.

> From the author's practice: one title, "ETHER 60 — Kinetic Architecture of Luminous Volume", sat on three different pieces at once. The files were different — checksums confirmed it. Three pieces, one name. The name was about the genre, not the work.

### 3. Translation

If the name is in a different language from the work, ask why. `Kinetic Apex`, `Voidframe`, `Nexus`, `Aether`, `Prism`, `Flux`, `Lumen` are not names; they are T-shirt slogans. A foreign-language name is allowed only when it names the subject more precisely than your own language does, and you can say how.

## Forbidden constructions

- Noun + noun with no subject: Voidframe, Lightform, Datascape
- Two or three abstract nouns in a row: "Architecture of Luminous Depth"
- "Digital" plus something lofty: "digital sanctuary", "digital poem"
- A serial number instead of a name: ETHER 80, piece-87
- A double name with a dash where the second half explains the first: "Kinetic Apex — a digital sanctuary". One name. Explanations live in the description.

## When the name won't come

The name won't come not because you are searching badly for words, but because **there is no subject yet**. That is a problem with the idea, not the name. Go back and answer WHAT you are making and WHAT it is about. The name will fall out on its own.

## Gate

- [ ] The name passes "I made ___"
- [ ] The name does not fit any other piece in the project
- [ ] No other piece in the project carries this name

Checked by the builder, not now (there is no page yet): the name is in `<title>` and the same name is on the page itself. It goes into the acceptance checks in `DIRECTION.md`.
